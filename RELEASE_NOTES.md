First public release.

**Download `AllyPad.zip`**, unzip it, then:

1. On the PC, run `allypad-receiver.exe`. Use its **Install driver** button if games do not see a controller, and note the PIN.
2. On the ROG Ally, set Armoury Crate's Control Mode to Gamepad and run `allypad-sender.exe`.
3. Tap **Laptop**, pick the PC and enter the PIN.

Both programs are unsigned: Windows SmartScreen will ask you to choose **More info**, then **Run anyway**.

What is in it: low-delay controller link for up to four players, touchscreen trackpad and keyboard, gyro aiming and tilt steering, game types with per-game switching, stick, trigger and button tuning, laptop volume and media keys, lock touch, power saving, and a tray icon on the PC side.

This is an early release. The newest parts (tray icon, one-click driver install) have had little real-world testing; please open an issue if something misbehaves.
